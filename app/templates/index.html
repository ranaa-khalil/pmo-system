RACI & Stakeholder Management

This tab manages who is involved in this project and what role they play. The RACI roles follow the RACI Matrix v2.3 from the Release Process. Assign the 6 required gate-keeper roles first (below), then add external stakeholders (clients, partners) who need to be informed or consulted.

① Required Roles for Release Process

These 6 roles must be assigned before a release can advance through V-cycle approval gates. Search and assign a user to each.

These roles are required as per the Release Process V-cycle approval gates. Assign each role to a team member in the Settings tab before planning a release.

② Assigned Team Members

System users who have been assigned a RACI role on this project. These are the people who will receive approval requests when a release advances through the V-cycle.

③ Add External Stakeholder

Add people outside the system (clients, partners, sponsors) who need to be Consulted or Informed about this project. They won't have system access but will be listed in the RACI matrix and can receive shared release notes.

④ RACI Legend

From RACI Matrix v2.3 — used to classify each person's involvement in project activities.

R
Responsible — does the actual work. Can be more than one.
A
Accountable — single owner with sign-off authority. Exactly one per activity.
C
Consulted — provides input before/while work is done. Two-way.
I
Informed — kept up to date on progress or outcome. One-way.
